# Pulse Phase 9.1 — Pilot Surface: Incident Assist

## Why Incident Assist First
- Highest operator visibility
- Strong evidence context
- Clear audit trail
- Low ambiguity in value

## Pilot Scope
- Suggest remediation proposal for selected incident
- Show impact preview + evidence refs
- Require operator confirmation
- Emit evidence receipt

## Pilot Non-Goals
- No direct execution
- No auto-assign/auto-close
- No cross-incident chained automation
